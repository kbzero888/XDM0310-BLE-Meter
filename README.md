# XDM0310-BLE-Meter

基于 **Kotlin + Jetpack Compose (Material 3)** 开发的 **XDM0310 电池内阻测试仪** Android 上位机应用，适配 **W02** 等标准 `FFE0/FFE1` 透传低功耗蓝牙（BLE）串口模块。

---

## 核心特性

* **全版本蓝牙权限自适应**：自动兼容 Android 12+ 精细蓝牙权限（`BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`）与旧版定位扫描权限，支持自动连接或从扫描列表中手动指定设备。
* **多地址独立轮询**：支持自定义 `0x01` ~ `0xFE` 目标模块地址，发送轮询指令时自动重算末尾 8 位累加和校验，并过滤非目标地址的应答报文。
* **轮询启停随时可控**：顶部状态栏提供独立轮询开关，可随时在「轮询中」与「已暂停」之间切换，方便调试单次指令或观察静态数据。
* **双视图无缝切换**：
  * **仪表盘视图**：高对比度大字体实时显示内阻（mΩ / Ω）、电池电压（正负极性）、仪表自身供电电压及电量百分比；内置连续同值防抖锁定（支持自定义 1~15 帧阈值），表笔离开（`oL`）后自动重置。
  * **蓝牙串口助手视图**：上半部分实时监视 `RX / TX` 十六进制报文流（带毫秒时间戳与自动滚屏）；下半部分左侧支持 HEX 指令编辑发送（内置「自动校验和」追加开关），右侧同步实时展示当前解析出的电压与内阻数值。
* **无限制本地持久化与 CSV 导出**：测量记录自动保存至本地（串口视图下的有效稳定读数同样自动入库），支持单条编辑电池备注、滑动/点击删除，以及一键导出带 UTF-8 BOM 头的标准 `.csv` 表格（Excel 打开中文表头不乱码）。

## 通讯协议参考

| 协议项 | 参数 / 报文结构 | 说明 |
| :--- | :--- | :--- |
| **BLE 服务 UUID** | `0000ffe0-0000-1000-8000-00805f9b34fb` | W02 默认串口透传主服务 |
| **读写/通知特征值** | `0000ffe1-0000-1000-8000-00805f9b34fb` | 开启 `Notify` 接收数据，向此特征值写入轮询或自定义指令 |
| **轮询请求帧（6 字节）** | `[Addr] A6 02 8A 8A [Checksum]` | 默认地址 `01` 时完整报文为 `01 A6 02 8A 8A BD`，末字节为前 5 字节累加和低 8 位 |
| **设备应答帧（16 字节）** | `Byte[0]` 地址，`Byte[3..6]` 内阻，`Byte[7..10]` 电压，`Byte[11..13]` 供电/电量，`Byte[15]` 校验和 | `Byte[3] != 0` 表示超量程（`oL`）；`Byte[15]` 为前 15 字节累加和低 8 位 |

## 云端编译与使用

1. **GitHub Actions 自动打包**：仓库内置 `.github/workflows/build.yml`，推送代码至 `main` / `master` 分支或手动触发 `workflow_dispatch` 后，即可在 **Actions → Artifacts** 中直接下载 `XDM0310-Meter-Debug` APK 安装包。
2. **连接注意事项**：
   * W02 为纯 BLE 模块，**无需**在手机系统「设置 → 蓝牙」中手动配对，直接在 App 内点击「自动连接」或「列表」即可。
   * 部分机型底层扫描 BLE 广播依赖系统定位服务，首次扫描前请确保手机**蓝牙**与**位置信息（GPS）**开关均已开启。
